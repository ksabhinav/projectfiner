# Privacy notice

Last updated: 3 September 2026

Project FINER is primarily a static public website. The repository version does not intentionally set first-party cookies or include a first-party audience-analytics service.

## Information processed during ordinary visits

Hosting, content-delivery, font and source-link providers may receive standard request metadata such as IP address, browser information, requested URL, referrer and time. Their handling of that information is governed by their own policies.

The site currently requests web fonts from Google Fonts. Following links to upstream publishers, GitHub or other external sites sends the request to that third party.

## Ask FINER

Questions submitted through Ask FINER are sent to the Project FINER API and then to Groq to generate a response. The application code does not intentionally write questions to a project database, but infrastructure and model providers may process or log requests under their own operational and privacy terms.

Do not submit personal financial information, credentials, confidential material, secrets or information about another person. Ask responses are experimental and should not be treated as financial advice or as a certified data query.

## Corrections and email

If you email Project FINER or file a GitHub issue, the information you provide is processed to respond to the report. GitHub issues are public. Use email rather than a public issue for information that should not be disclosed openly.

## Children and sensitive data

FINER is a general research product and is not designed to collect information from children. The project does not seek sensitive personal data.

## Contact

Questions or requests about this notice can be sent to `mail@projectfiner.com`.

This notice describes the repository version of the product. It must be updated if analytics, accounts, persistent query storage or other data-collection features are added.
